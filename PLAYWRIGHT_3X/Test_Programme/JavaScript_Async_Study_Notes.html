JavaScript Async Study Notes

Async Programming in JavaScript

Simple notes for learning asynchronous JavaScript.

1. Callback

A callback is a function passed to another function. It runs later, after a task finishes. 

function fetchData(callback) {
  setTimeout(() => {
    callback("Data loaded");
  }, 1000);
}

fetchData((result) => {
  console.log(result);
});

Good: Simple and easy to understand.

Bad: Too many nested callbacks creates callback hell.

Callback hell means code becomes difficult to read and maintain when functions are nested inside each other.

2. Promise

A Promise is an object that represents a future result. It can be successful or failed. 

const promise = new Promise((resolve, reject) => {
  const done = true;

  setTimeout(() => {
    if (done) {
      resolve("Success");
    } else {
      reject("Error");
    }
  }, 1000);
});

promise
  .then((value) => console.log(value))
  .catch((error) => console.log(error));

States of Promise:

  • pending - not finished yet
  • fulfilled - success
  • rejected - failure

3. Async

The keyword async is used before a function to make it asynchronous. 

async function showMessage() {
  return "Hello";
}

showMessage().then((msg) => console.log(msg));

An async function always returns a Promise automatically.

This makes async code easier to write and read than callback-based code.

4. Await

The keyword await pauses execution inside an async function until the Promise finishes. 

async function getData() {
  const result = await new Promise((resolve) => {
    setTimeout(() => resolve("Loaded"), 2000);
  });

  console.log(result);
}

getData();

await makes asynchronous code look more like normal sequential code.

You can use await only inside an async function.

5. Promise.all

Promise.all() waits for all promises to finish before continuing. 

const p1 = Promise.resolve("A");
const p2 = new Promise((resolve) => setTimeout(() => resolve("B"), 1000));
const p3 = new Promise((resolve) => setTimeout(() => resolve("C"), 2000));

Promise.all([p1, p2, p3]).then((values) => {
  console.log(values);
});
[ 'A', 'B', 'C' ]

Use case: When all tasks must complete before moving ahead.

6. Promise.race

Promise.race() returns the result of the first promise that settles. 

const slow = new Promise((resolve) => setTimeout(() => resolve("Slow"), 2000));
const fast = new Promise((resolve) => setTimeout(() => resolve("Fast"), 500));

Promise.race([slow, fast]).then((result) => {
  console.log(result);
});
Fast

Use case: When you want to get the fastest response.

Comparison

Promise.all

  • Waits for all
  • Returns all results
  • Fails if one fails

Promise.race

  • Returns first result
  • Does not wait for all
  • Faster response wins

Short Summary

  • Callback = function called later.
  • new Promise = handles async success/failure.
  • async = makes function asynchronous.
  • await = waits for Promise result.
  • Promise.all = wait for all tasks.
  • Promise.race = use the first finished task.
In modern JavaScript, async and await are the most common and readable way to handle asynchronous work.
