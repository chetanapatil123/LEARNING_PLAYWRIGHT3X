JavaScript Async Promises

JavaScript Async Programming Tutorial

JavaScript runs in a single thread, but it can handle time-consuming tasks without freezing the browser by using asynchronous programming techniques such as callbacks, promises, and async/await.

1. Callback

A callback is a function that is passed into another function and runs later after a task is completed. It is one of the oldest ways to work with asynchronous code in JavaScript. 

function fetchData(callback) {
  setTimeout(() => {
    const data = "User details loaded";
    callback(data);
  }, 1000);
}

fetchData(function (result) {
  console.log(result);
});

How it works

  • The main function starts a background timer.
  • After 1 second, it executes the callback.
  • The callback receives the result and prints it.
Important: Callback nesting can become hard to manage, which is called callback hell.

2. new Promise

A Promise represents a value that may be available now, later, or never. It helps manage asynchronous work more cleanly than traditional callbacks. 

const promise = new Promise((resolve, reject) => {
  const success = true;

  setTimeout(() => {
    if (success) {
      resolve("Operation successful");
    } else {
      reject("Operation failed");
    }
  }, 1000);
});

promise
  .then((result) => console.log(result))
  .catch((error) => console.log(error));

A promise has three states: pending, fulfilled, and rejected.

Use case: When a task may succeed or fail asynchronously, and you want a structured result-handling approach.

3. Async

The async keyword is used before a function to make it asynchronous. An async function always returns a Promise. 

async function getMessage() {
  return "Hello from async function";
}

getMessage().then((value) => {
  console.log(value);
});

Even if you return a simple value, JavaScript wraps it inside a Promise automatically.

4. Await

The await keyword pauses the execution of an async function until the Promise is resolved. This makes asynchronous code easier to read and write. 

async function getData() {
  const data = await new Promise((resolve) => {
    setTimeout(() => resolve("Data received"), 2000);
  });

  console.log(data);
}

getData();

Without await, you would need to chain .then() repeatedly. With await, the code reads more like normal JavaScript.

Rule: You can only use await inside an async function.

5. Promise.all

Promise.all() accepts multiple promises and waits for all of them to finish. It resolves only when every promise succeeds. If one promise rejects, the whole operation rejects. 

const p1 = Promise.resolve("A");
const p2 = new Promise((resolve) => setTimeout(() => resolve("B"), 1000));
const p3 = new Promise((resolve) => setTimeout(() => resolve("C"), 2000));

Promise.all([p1, p2, p3]).then((values) => {
  console.log(values);
});
[ 'A', 'B', 'C' ]

Use it when: multiple independent tasks must all complete before continuing.

6. Promise.race

Promise.race() settles as soon as one of the promises resolves or rejects. It does not wait for all of them. 

const slow = new Promise((resolve) => setTimeout(() => resolve("Slow result"), 2000));
const fast = new Promise((resolve) => setTimeout(() => resolve("Fast result"), 500));

Promise.race([slow, fast]).then((result) => {
  console.log(result);
});
Fast result

Use it when: you only care about the first result, such as timeouts or fastest response wins.

Promise.all vs Promise.race

Promise.all
  • Waits for all promises.
  • Returns results in the same order.
  • Fails if any promise fails.
Promise.race
  • Returns the first settled result.
  • Does not wait for all promises.
  • May finish with success or failure.

Real-World Example

async function fetchUser() {
  return new Promise((resolve) => {
    setTimeout(() => resolve("Amit"), 1000);
  });
}

async function fetchPosts() {
  return new Promise((resolve) => {
    setTimeout(() => resolve(["Post 1", "Post 2"]), 1500);
  });
}

async function loadDashboard() {
  const [user, posts] = await Promise.all([
    fetchUser(),
    fetchPosts()
  ]);

  console.log("User:", user);
  console.log("Posts:", posts);
}

loadDashboard();

This pattern is widely used when an app must fetch several APIs before rendering the page.

Summary

  • Callback: function executed after an async task finishes.
  • new Promise: creates a promise object for async work.
  • async: makes a function return a Promise.
  • await: waits for a promise in an async function.
  • Promise.all: waits for all promises to complete.
  • Promise.race: completes on the first settled promise.
Modern JavaScript usually prefers async/await because it is cleaner and easier to understand than nested callbacks.
