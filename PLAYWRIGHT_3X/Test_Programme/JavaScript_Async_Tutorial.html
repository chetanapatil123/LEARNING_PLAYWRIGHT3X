JavaScript Async Promises

JavaScript Async Programming Tutorial

JavaScript is single-threaded, but it can handle long tasks without blocking the main thread using callbacks, Promises, and the async/await syntax.

1. Callback

A callback is a function passed as an argument to another function and executed later when a task completes. It is one of the oldest ways to handle asynchronous work in JavaScript. 

function fetchData(callback) {
  setTimeout(() => {
    const data = "User details loaded";
    callback(data);
  }, 1000);
}

fetchData(function (result) {
  console.log(result);
});

How it works:

  • We call fetchData.
  • It waits for 1 second.
  • Then it calls the callback with the result.
Problem: Too many nested callbacks can lead to “callback hell”, where code becomes hard to read and maintain.

2. new Promise

A Promise represents the eventual result of an asynchronous operation. It can be in one of three states: pending, fulfilled, or rejected. 

const promise = new Promise((resolve, reject) => {
  const success = true;

  setTimeout(() => {
    if (success) {
      resolve("Operation successful");
    } else {
      reject("Operation failed");
    }
  }, 1000);
});

promise
  .then((result) => console.log(result))
  .catch((error) => console.log(error));

Key idea: A promise gives a cleaner way to handle async results than callbacks.

When to use: When you need to perform an async task and handle success or failure in a structured way.

3. Async

The async keyword is used before a function to make it asynchronous. An async function always returns a Promise. 

async function getMessage() {
  return "Hello from async function";
}

getMessage().then((value) => console.log(value));

Important: Even if the function returns a normal value, JavaScript wraps it in a Promise automatically.

Example with delay: 
async function loadUser() {
  return new Promise((resolve) => {
    setTimeout(() => resolve("Amit"), 1500);
  });
}

loadUser().then((name) => console.log(name));

4. Await

The await keyword pauses execution inside an async function until a Promise is resolved or rejected. It makes async code look like synchronous code and is easier to read. 

async function getData() {
  const data = await new Promise((resolve) => {
    setTimeout(() => resolve("Data received"), 2000);
  });

  console.log(data);
}

getData();

Why it matters: It makes waiting for async operations simple and readable.

You can only use await inside an async function.

5. Promise.all

Promise.all() takes an array of Promises and waits for all of them to finish. It resolves only when every promise succeeds. If any one fails, it rejects immediately. 

const p1 = Promise.resolve("A");
const p2 = new Promise((resolve) => setTimeout(() => resolve("B"), 1000));
const p3 = new Promise((resolve) => setTimeout(() => resolve("C"), 2000));

Promise.all([p1, p2, p3]).then((values) => {
  console.log(values);
});
[ 'A', 'B', 'C' ]

Best use: When several independent tasks must complete before moving ahead.

6. Promise.race

Promise.race() returns the result of the first Promise that settles (either resolves or rejects). It does not wait for all Promises to finish. 

const slow = new Promise((resolve) => setTimeout(() => resolve("Slow result"), 2000));
const fast = new Promise((resolve) => setTimeout(() => resolve("Fast result"), 500));

Promise.race([slow, fast]).then((result) => {
  console.log(result);
});
Fast result

Best use: When you care about the fastest response, such as timeout logic, retry, or first-response wins.

Difference Between Promise.all and Promise.race

Promise.all
  • Waits for all Promises.
  • Returns an array of results.
  • Fails if any promise rejects.
Promise.race
  • Returns the first settled Promise.
  • Does not wait for all.
  • Can finish on success or failure.

Full Example: async + await + Promise.all

async function fetchUser() {
  return new Promise((resolve) => setTimeout(() => resolve("User: Amit"), 1000));
}

async function fetchPosts() {
  return new Promise((resolve) => setTimeout(() => resolve("Posts: 5"), 1500));
}

async function loadDashboard() {
  const [user, posts] = await Promise.all([
    fetchUser(),
    fetchPosts()
  ]);

  console.log(user);
  console.log(posts);
}

loadDashboard();

This pattern is common in real applications. The dashboard waits for all data requests to complete before rendering.

Summary

  • Callback: Function passed to another function and executed later.
  • new Promise: Creates a Promise that resolves or rejects asynchronously.
  • async: Makes a function return a Promise.
  • await: Waits for a Promise inside an async function.
  • Promise.all: Waits for all Promises to finish.
  • Promise.race: Uses the fastest or first settled Promise.
Modern JavaScript prefers async/await over nested callbacks because it is cleaner and easier to understand.
